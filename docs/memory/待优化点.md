title: 待优化点
---

1. **回填 Bug（真问题）**：`search` 返回的 `content` / `importance` 取自向量库元数据而非 JPA，`update` 向量更新失败时会返回陈旧数据——应改用回查到的 JPA 实体回填。
2. **陈旧向量不清理**：已删向量只过滤不删除，越积越多挤占 topK 名额——可加惰性删除（过滤时异步 `vectorStore.delete()`）。
3. **JPA 有、向量无**：`add` 后向量被误删的记忆永远搜不到——需定时对账任务补齐。
4. **写入一致性不对称**：`add` 向量失败会回滚，但 `update` / `delete` 向量失败仅告警——彻底方案是 Outbox 模式保证最终一致。
