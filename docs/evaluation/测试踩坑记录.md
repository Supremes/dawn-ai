### negative cases
- 解释: 检验"抗干扰"能力，面对语义相似但实际无关、甚至误导性的内容时，不会召回。
- 问题: 容易召回一些无关的用例文档，导致无法通过 negative cases
- 方案：
	- query 处理前：引入 query domain classifier，判断问题是否属于知识库 
	- query 处理中： 开启 cross-encoder 做 rerank排序，不过滤，决定哪个更相关排在前面
	- [ ] query 处理后：实现 query-docuemnt entailment  gate: 不看关键词是否相似、不看 embedding 距离，而是判断文档内是否蕴含/支持/足以回答 query
