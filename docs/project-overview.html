️ 项目概述

Dawn AI是一个完整的AI Agent应用，使用Python重写，采用LangChain和LangGraph框架实现。项目从Java/Spring Boot架构迁移到Python生态，提供更灵活的AI编排能力和更丰富的工具集成。

✨ 核心功能

ReAct Agent编排

使用LangGraph实现Reasoning + Acting循环，支持多步骤任务执行、工具调用和动态规划。

RAG知识检索

基于PGVector的向量检索，支持文档摄取、语义搜索和上下文增强生成。

对话记忆管理

Redis-backed的对话历史管理，支持会话持久化和上下文窗口控制。

⚡ 流式响应

支持SSE（Server-Sent Events）流式输出，实时返回Agent思考过程和工具调用结果。

️ 工具集成

可扩展的工具系统，内置知识库搜索和计算器，支持自定义工具扩展。

️ 微服务架构

FastAPI提供高性能REST API，支持异步处理和并发请求。

模块详解

1. Agent编排器 (agent_orchestrator.py)

核心模块，使用LangGraph实现ReAct（Reasoning + Acting）循环：

  • 状态图（StateGraph）管理Agent执行流程
  • 动态工具调用和结果处理
  • 支持同步和异步流式执行
  • 可配置的最大执行步骤限制

2. Memory服务 (memory_service.py)

Redis-backed对话历史管理：

  • 会话级别的消息存储
  • 自动TTL过期（24小时）
  • 支持历史消息检索和清除

3. RAG服务 (rag_service.py)

向量检索和文档管理：

  • 文档摄取和向量化
  • 语义相似度搜索
  • PGVector存储和索引

4. API层 (api/)

FastAPI REST API：

  • 同步Chat API
  • 流式Chat API（SSE）
  • RAG摄取和搜索API
  • 自动API文档生成

快速开始

1. 环境准备

# 克隆项目 cd /Users/junkangd/projects/dawn-ai-python # 安装依赖 uv sync # 配置环境变量 cp .env.example .env # 编辑 .env 文件配置API密钥

2. 启动服务

# 启动依赖服务 docker compose up -d # 启动应用 uv run dawn-ai

3. 运行测试

# 运行所有测试 uv run pytest tests/ -v # 查看覆盖率 uv run pytest tests/ --cov=dawn_ai --cov-report=html

4. API调用示例

# 同步Chat curl -X POST http://localhost:8000/api/v1/chat \ -H "Content-Type: application/json" \ -d '{"message": "北京天气怎么样？", "session_id": "test-001"}' # 流式Chat curl -X POST http://localhost:8000/api/v1/chat/stream \ -H "Content-Type: application/json" \ -d '{"message": "介绍一下人工智能"}' # 文档摄取 curl -X POST http://localhost:8000/api/v1/rag/ingest \ -H "Content-Type: application/json" \ -d '{"content": "退款政策：30天内可退", "source": "policy"}' # 知识搜索 curl "http://localhost:8000/api/v1/rag/search?query=退款&top_k=3"
