核心功能

强大的AI Agent能力，灵活的工具集成

ReAct Agent编排

使用LangGraph实现Reasoning + Acting循环，支持多步骤任务执行、工具调用和动态规划。

RAG知识检索

基于PGVector的向量检索，支持文档摄取、语义搜索和上下文增强生成。

对话记忆管理

Redis-backed的对话历史管理，支持会话持久化和上下文窗口控制。

⚡

流式响应

支持SSE流式输出，实时返回Agent思考过程和工具调用结果。

️

工具集成

可扩展的工具系统，内置知识库搜索和计算器，支持自定义工具扩展。

️

微服务架构

FastAPI提供高性能REST API，支持异步处理和并发请求。
