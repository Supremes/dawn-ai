04

问题诊断

RAG Pipeline 未验证 — 向量库基建问题

  • Embedding 维度不匹配：配置 2048 维 vs 表定义可能为 1024 维
  • DataIntegrityViolation：向量插入时 SQL 约束异常，测试文档无法索引
  • 结果：RAG 检索返回空结果，0/3 用例通过
  • 修复方向：重建向量库表（drop + create with correct dimensions），或使用 mock embedding 测试

Answer 完整性部分通过 — Agent 回答策略问题

  • Agent 从训练知识回答：未优先从检索文档中提取，导致遗漏 RAG 相关细节
  • Judge 评分严格：要求覆盖所有子主题，缺少任何一个即扣分
  • 结果：1/3 用例通过，avg=2.0
  • 修复方向：优化 answerCriteria 描述、降低通过阈值（3.5→3.0）、确保 RAG 文档可检索

LLM 429 限流 — 2 个用例未完成

  • 影响：answer_002、answer_003、rag_recall_002、rag_recall_003 未完成
  • 已采取措施：AgentOrchestrator 添加指数退避重试（5s/10s/20s）+ case 间 3s 延迟
  • 仍不够：需要更长延迟或分批运行
  • 修复方向：case 间延迟增加到 10-15 秒，或分批运行（每次 2-3 个维度）
