     edit
     Prompt 管理 + 中文 BM25 (zhparser) 实施计划

     Context

     当前项目存在两个核心问题：
     1. Prompt 散落：6 处核心 LLM system prompt 内联在 Java
     代码中，无法统一维护、版本管理和热更新
     2. 中文检索缺失：BM25 稀疏检索使用 PostgreSQL english
     配置，中文内容无法分词和匹配

     目标：创建 git worktree 工作区，实现集中式 Prompt 管理，并通过 zhparser
     扩展让 PostgreSQL FTS 支持中文分词。

     ---
     第一步：Git Worktree

     git worktree add .worktrees/feat/prompt-chinese-bm25 -b
     feat/prompt-chinese-bm25

     后续所有改动在 worktree 中进行。

     ---
     第二步：中文 BM25 (zhparser)

     2.1 新建 docker/postgres/Dockerfile

     基于 pgvector/pgvector:0.8.0-pg16 编译安装 zhparser：

     FROM pgvector/pgvector:0.8.0-pg16
     RUN apt-get update && apt-get install -y --no-install-recommends \
             build-essential postgresql-server-dev-16 git \
         && git clone https://github.com/amutu/zhparser.git /tmp/zhparser \
         && cd /tmp/zhparser && make && make install \
         && cd / && rm -rf /tmp/zhparser \
         && apt-get purge -y build-essential postgresql-server-dev-16 git \
         && apt-get autoremove -y && rm -rf /var/lib/apt/lists/*

     2.2 新建 scripts/init-zhparser.sql

     CREATE EXTENSION IF NOT EXISTS zhparser;
     CREATE TEXT SEARCH CONFIGURATION chinese (PARSER = zhparser);
     ALTER TEXT SEARCH CONFIGURATION chinese ADD MAPPING FOR n,v,a,i,e,l WITH
     simple;

     2.3 修改 docker-compose.yml

     - postgres service: image → build: ./docker/postgres
     - 挂载 init-zhparser.sql 到 /docker-entrypoint-initdb.d/

     2.4 修改 src/main/resources/application.yml

     text-search-config: chinese  # 原为 english

     2.5 修改 OverlapTextSplitter.java (line 29)

     添加中文标点到分块边界检测：

     private static final List<Character> DEFAULT_PUNCTUATION_MARKS = List.of(
         '.', '?', '!', '\n',

     - docker compose build postgres && docker compose down -v && docker compose
